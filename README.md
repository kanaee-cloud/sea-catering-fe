# SEA Catering Front-End

Welcome to the SEA Catering Front-End project! This application is designed to provide a seamless and interactive experience for users who wish to customize and order healthy meals delivered across Indonesia. The project is built using modern web technologies, ensuring a responsive and user-friendly interface.

## Installation

To get started with the project, follow these steps:

1. Clone the repository:
   ```bash
   git clone https://github.com/kanaee-cloud/sea-catering-fe.git
   cd sea-catering-fe
   ```

2. Install the dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm run dev
   ```

## Usage

Once the development server is running, you can access the application in your web browser at `http://localhost:5173` (or the specified port in your terminal).

## Features

- **Responsive Design**: The application is designed to work seamlessly on both desktop and mobile devices.
- **User Authentication**: Secure user authentication for both customers and admins.
- **Subscription Management**: Easily manage meal subscriptions with options to pause, resume, or cancel.
- **Testimonials**: View and submit customer testimonials to share your experience.
- **Admin Dashboard**: Admins can manage users, subscriptions, and more.
